# Phase 4 — Living Brain + Advanced Civilization Design

Phase 4 replaces the prototype HUD with a more alive interface and a cleaner local brain shell.

## Added

- Direct listening loop while the app is open.
- No touch-to-speak label.
- Full-screen cognitive civilization HUD.
- Reactor core, hex lattice, particles, neural trace, response dock, telemetry panels.
- Local memory vault using SharedPreferences.
- Identity commands such as `who am I`, `call me ...`, `my name is ...`.
- Memory commands such as `remember that ...`, `what do you remember`, `clear memory`.
- Diagnostics responses for battery and device state.
- Mode shifts: tactical, stealth, alert.

## Brain Roadmap

This version is not omniscient. It contains a local cognition shell. For the "whole brain" layer, connect:

1. Cloud LLM gateway.
2. Retrieval memory database.
3. Web search provider.
4. Tool execution router.
5. Safety and permission policy.

No API keys are stored in the repo. Add them only through secure runtime configuration later.
